I'm a **Cybersecurity student and developer** focused on understanding how systems, networks and applications work — and how they can be made more secure.

My approach is simple:

> **If I want to understand something, I build it.
> If I want to master something, I break it.
> If I want to secure something, I first understand how it fails.**

My interests live at the intersection of:

* 🔐 Cybersecurity & Ethical Hacking
* 🌐 Network Engineering & Infrastructure
